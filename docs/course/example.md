# 示例课程：如何写一篇学习笔记

> 课程名称：示例课程 · 作者：CHENNYO

这里用一两句话概括这篇文章：学习了什么、解决了什么问题，或者希望读者获得什么。

## 1. 学习目标

- 理解本节课的核心概念。
- 用自己的话整理知识点。
- 完成一个简单练习。

## 2. 核心知识

文章使用 **Markdown** 格式编写。用 `#` 表示文章标题，用 `##` 表示小节标题，用 `###` 表示更小一级的标题。

正文直接写在这里，段落之间空一行。可以用 **加粗** 强调重点，也可以用 *斜体* 补充说明。

### 列表和表格

1. 先介绍背景。
2. 再解释具体步骤。
3. 最后记录结论。

| 知识点 | 我的理解 |
| --- | --- |
| 标题 | 让文章结构清楚 |
| 链接 | 方便查看参考资料 |
| 代码块 | 展示可以运行的示例 |

## 3. 示例代码

在三枚反引号后写上语言名称，就能展示代码：

```python
def greet(name):
    return f"你好，{name}！"

print(greet("CHENNYO"))
```

!!! note "学习提示"
    这里可以记录容易忘记的细节，或提醒自己下次复习的内容。

## 4. 练习与总结

尝试把上面示例中的名字改成自己的名字，再记录你的结果。

- 今天学到了什么？
- 哪个地方还不明白？
- 下一步准备尝试什么？

## 以后如何新增文章

1. 在 `docs/course/` 文件夹里新建一个文件，例如 `my-first-note.md`。
2. 参考这篇文章的格式，填写标题和正文。
3. 打开 `docs/course/index.md`，在文章列表中添加一行：

```markdown
- [我的第一篇笔记](my-first-note.md) — 一句话简介。
```

4. 保存文件，本地预览会自动更新。
